# DAREU LM113 跨平台驱动开发规划 (2026-10-05)

## 1. 调研与逆向验证结论

通过对原驱动二进制文件与当前插入设备的逆向分析与脚本验证，得出以下核心结论：
- **方案商与架构**：采用荣腾科技（Rongteng）定制的 Holtek（盛群）USB MCU 方案，设备为免驱标准 USB HID 复合设备（包含键盘、鼠标与 Vendor-Defined 配置接口）。
- **通信通道**：上位机通过标准 `hidapi` 与 `UsagePage: 0xff01` 的 Vendor 接口通信。
- **报文协议与密钥**：
  - 配置下发：采用 **9 字节 HID Feature Report**（1 字节 ReportID + 8 字节 Payload）。
  - 协议混淆：原驱动使用对称混淆算法（字节对调 + 循环位移 + XOR + 密钥掩码），硬编码密钥字符串为 **`RoNgtEng`**（`52 6f 4e 67 74 45 6e 67`）。
  - 状态上报：鼠标通过 Interrupt In 上报 4 字节数据（如 `0x06, 0x07, ..., stage`）通知 DPI 档位切换。
- **跨平台可行性**：Windows / Linux / macOS 均有官方或成熟的 `hidapi` 支持，无需编写内核驱动；Linux 仅需一条 `udev` 规则开放设备读写。

## 3. 分阶段开发规划 (5 大阶段)

### 阶段一：协议编解码器与通信 PoC 验证
- **目标**：在 Python 虚拟环境中完成完整指令闭环，并移植到 C# 协议基础库。
- **工作项**：
  1. 实现 `RoNgtEng` 混淆算法与逆向解密算法的 C#/Python 对应版本。
  2. 构造 DPI 切换（400~6000）、回报率（125/250/500/1000Hz）、灯效模式（常亮/呼吸/霓虹/RGB颜色）的 Feature Report 数据包。
  3. 执行实机写入测试，验证鼠标灯光与灵敏度实时生效；监听读取 4 字节 DPI 上报包。
- **交付物**：`Dareu.LM113.Protocol.Tests` 单元测试与端到端控制台 PoC。

### 阶段二：核心领域模型与驱动服务层封装
- **目标**：封装设备抽象层，屏蔽底层 USB HID 细节，提供强类型领域接口。
- **工作项**：
  1. 建立数据模型：`MouseProfile`、`DpiStageConfig`、`LightingConfig`、`KeyBindingConfig`。
  2. 实现 `DareuDeviceManager`：负责设备热插拔自动检测、连接维持与重连机制。
  3. 实现板载配置拉取与落盘序列化（兼容原版 `p1.bin` / JSON 格式配置导出导入）。
- **交付物**：独立的 .NET 类库 `Dareu.LM113.Core` 与 `Dareu.LM113.Protocol`。

### 阶段三：Avalonia 现代桌面 GUI 开发
- **目标**：构建跨平台响应式桌面端界面，提供远超原版 Qt4 体验的现代交互。
- **工作项**：
  1. 引入原版 `TM543\Skins` 鼠标高精度资源，制作交互式鼠标键位指示大图。
  2. **DPI 页面**：彩色档位滑块、多段开关、X/Y 轴独立灵敏度、回报率单选框。
  3. **灯光设置页**：灯效模式选择（常亮/呼吸/指动/霓虹）、HSV/RGB 拾色器、速度与亮度调节。
  4. **按键映射页**：按键重映射下拉列表、多媒体键支持、宏按键配置面板。
  5. **系统托盘与自启**：支持托盘常驻与 DPI 档位气泡通知。
- **交付物**：Avalonia 主工程 `Dareu.LM113.App`。

### 阶段四：跨平台系统适配与权限处理
- **目标**：解决 Linux 与 macOS 平台的硬件访问权限与环境依赖。
- **工作项**：
  1. **Linux 适配**：内置 `udev` 规则自动检测与安装向导（针对 VID 0x260d / 0x258a 设备添加 0666 权限）；支持 Wayland/X11 环境。
  2. **macOS 适配**：配置 `Info.plist`，处理 IOHID 权限提示与 macOS 菜单栏适配。
  3. **Windows 适配**：处理单实例互斥运行与开机自启动注册表/快捷方式。
- **交付物**：各平台打包脚本与权限自检向导。

### 阶段五：GitHub Actions CI/CD 与全自动化 Release
- **目标**：复用 KugouMusic.NET 的自动化构建流水线，实现 Tag 触发的多平台产物发布。
- **工作项**：
  1. 编写 `.github/workflows/release.yml`，设置矩阵构建：
     - Windows: `win-x64`, `win-arm64`（发布单文件免安装 EXE 与 MSI 安装包）。
     - Linux: `linux-x64`, `linux-arm64`（发布独立二进制包、deb、rpm 与 AppImage 安装包）。
     - macOS: `osx-x64`, `osx-arm64`（打包 `.app` 与 `.dmg`，生成 `.icns` 图标）。
  2. 配置发布产物自动上传到 GitHub Release 并生成 ChangeLog。
- **交付物**：完整的 GitHub Actions CI 工作流与一键发布体系。
